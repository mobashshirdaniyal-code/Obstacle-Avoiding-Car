# Obstacle-Avoiding-Car
This is a robotic car which detects obstacle if any in it's path and selects the path which is free from obstacles.

## COMPONENTS REQUIRED
<ol type="1">
  <li>DC Gear Motors</li>
  <li>Wheels</li>
  <li>Arduino Uno</li>
  <li>L293D Motor Driver</li>
  <li>Servo Motor</li>
  <li>Ultrasonic Sensor</li>
  <li>Male to Female Jumper Wires</li>
  <li>Power Resource</li>
</ol>
